# 家事RPG

ブラウザベースの家事管理RPGアプリケーション。家事を完了してレベルアップし、部屋を飾ってカスタマイズできます。

## 機能

### クエストページ
- 家事を選択して実行
- 経験値（XP）を獲得
- レベルアップでご褒美獲得
- 天気情報を表示
- クエスト履歴管理

### 装飾ゲーム（decorator-featureブランチ）
- デコポイントを使用して部屋を飾る
- 家具、植物、ライト、壁紙を配置
- アイテムのドラッグ・回転・削除
- クエスト完了でポイント獲得

## セットアップ

### 必要なもの
- 最新のWebブラウザ
- Gitクライアント

### インストール

```bash
# リポジトリをクローン
git clone <repository-url>
cd youthousehold_rpg

# mainブランチを確認
git branch -a

# decorator-featureブランチに切り替え（装飾機能を使用する場合）
git checkout decorator-feature
```

## 使用方法

### ローカルで実行

1. プロジェクトディレクトリで`index.html`をブラウザで開く
2. または簡易サーバーで実行：
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# Node.js（http-serverをインストール後）
npx http-server
```

3. ブラウザで `http://localhost:8000` を開く

## ブランチ管理

### main（メインブランチ）
- クエストRPG機能
- 天気情報表示
- ユーザーデータ管理

### decorator-feature
- 装飾ゲーム機能（クレイトゲーム）
- 部屋のカスタマイズ
- アイテム配置システム

### ブランチの切り替え

```bash
# mainブランチに戻る
git checkout main

# decorator-featureに切り替える
git checkout decorator-feature

# または最新Gitの場合
git switch decorator-feature
```

## ファイル構成
````
index.html`: Main page structure.
style.css`: App styling.
script.js`: Chore selection, XP, and reward logic.
```
